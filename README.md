
# ⭐ Star Collector Game

A 2D collection and survival game created with Scratch as part of CS50x Problem Set 0.

## 🎮 About the Project

In Star Collector Game, the player controls the Batter character and collects stars while avoiding an enemy Bat.

The goal is to collect enough stars to reach a score of 10 and win the game.

## 🛠️ Built With

- Scratch
- CS50x — Problem Set 0

## ⚙️ Game Mechanics

- Keyboard-controlled player movement
- An enemy Bat that follows the player
- A collectible Star
- Score tracking with a variable
- Random repositioning of the Star after collection
- Enemy movement speed increases based on the score
- Win condition at a score of 10
- Game-over condition
- Broadcast messages for game events

## ▶️ How to Play

1. Open `Star Collector Game.sb3` with Scratch.
2. Start the game with the green flag.
3. Move the player using the keyboard.
4. Collect stars to increase your score.
5. Avoid the Bat.
6. Reach a score of 10 to win.
